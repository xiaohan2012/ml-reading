# 第 1 层:公共地基 —— 电路 = 子图,knockout = 给子图赋予"行为"

## 1.1 先把模型看成一张计算图 $M$

- **节点**:前向传播里的每一项——注意力头、MLP、嵌入。
  - 在 IOI 里,节点粒度更细:是 **(head, token 位置)** 对。比如"第 9 层第 6 号头在 END 位置"是一个节点,同一个头在 S2 位置是另一个节点。
  - 为什么带位置?因为 IOI 的核心是"信息在不同 token 位置之间搬运",同一个头在不同位置干的事可能完全不同。
- **边**:节点之间通过残差流的读写发生的交互。(细节见文末"边 = QKV 上的可分离项")
- **约定**:这篇文章**只把注意力头当作可切换的节点**;MLP、LayerNorm、嵌入**永远开着**,不去动它们(他们发现除第一层 MLP 外,MLP 逐个敲掉影响不大,所以选择不碰,聚焦在注意力头上)。

**电路 $C$** 就是这张图的一个**子图**——负责某个行为(这里是 IOI)的那部分节点。到这里,和 "circuit = pattern" 完全一致。

## 1.2 核心难题:一堆节点**还不是**一个"行为"

这是第 1 层最关键、最容易被跳过的一点。

你选出一个子图 $C$(一堆 head),但你**不能把它单独拎出来跑**——它嵌在 $M$ 里,少了其他节点,前向传播根本无法完成。那"这个子图到底算出了什么"这句话,**在数学上还没有定义**。

用数据挖掘的语言:pattern 有了,但 pattern 的**求值函数**还没定义。你得先说清楚"给定一个子图,它对应的输出是什么",才能去谈它的质量。

## 1.3 knockout:用"敲掉补集"来定义 $C(x)$

作者的解法很巧:**不去单独运行 $C$,而是运行完整的 $M$,但把不在 $C$ 里的所有节点 $M \setminus C$ 全部"敲掉"。** 剩下这个被改造过的网络的输出,就**定义**为 $C(x)$。

$$C(x) \;\triangleq\; M(x)\ \text{在}\ M\setminus C\ \text{全部被 knockout 后的输出}$$

- 这是一个**定义式**,不是近似。"子图 $C$ 的行为"从此有了明确含义。
- 直觉:与其问"只有这几个 head 能算出什么"(没法跑),不如问"把其他 head 都关掉、只留这几个,模型还能做对多少"。

> **这就是第 1 层的题眼**:knockout 是那台把"几何对象(一个子图)"翻译成"可测量的行为(一个函数 $C(x)$)"的机器。没有它,circuit 只是一个静态集合;有了它,circuit 才有能被打分的行为。

### 补充:"定义式,不是近似"是什么意思?"$C$ 的行为"到底是什么含义?

> 疑问:什么叫"定义式"?什么叫"有了明确含义"?什么含义?

**1)"定义"和"近似"是两种不同的动作**

- **近似(approximation)**:先有一个**已存在的目标量** $T$,你算出别的东西去逼近它,两者有误差。"$a\approx T$"是在**断言一个事实**(有对错、有误差大小)。
- **定义式(记作 $\triangleq$ 或 $:=$)**:你在**引入一个全新名词**,并**规定它就指这个东西**。它不可能"错"、也没有"误差"——因为在这行字之前,这名词根本不存在,没有别的东西可比。

$C(x)\triangleq[\text{把 }M\setminus C\text{ 敲掉后跑 }M\text{ 的输出}]$ 里的 $\triangleq$ 就是**规定**:"我从现在起,把'电路 $C$ 的行为'这句话**定义为**这个过程的输出。"

**2)为什么"$C$ 的行为"需要被定义**

因为**一堆节点本身不是函数,没有输出**。$C$ 只是个子集(一堆 head),问"$C$ 算出了什么?"此刻**没有真值**——就像问"集合 $\{3,7,9\}$ 的输出是多少"。要让"$C$ 做 IOI 好不好"这种话**可判断真假**,必须先把 $C$ 变成一个"输入→输出"的函数。knockout **就是把子集造成函数的那一步**。

**3)用统计的语言:$C(x)$ 就像一个估计量(estimator)**

| 统计 | 这篇文章 |
|---|---|
| 估计量 $\hat\theta := \frac{1}{n}\sum x_i$(一个**过程/公式**) | $C(x)$ :=(敲掉补集后跑网络的**过程**) |
| 真参数 $\theta$ | 完整模型行为 $F(M)$ |
| 估计误差 $\lvert\hat\theta - \theta\rvert$ | faithfulness $\lvert F(C)-F(M)\rvert$ |

- 写下 $\hat\theta := \frac1n\sum x_i$ 是**定义**——$\hat\theta$ 不是在"近似"什么,它**就是**这个求和给出的数。
- $\hat\theta$ 和真参数 $\theta$ 接近不接近,是**另一层**问题(偏差/方差),那里才有"近似"和误差。

**关键**:别以为 $C(x)$ 是在"近似还原 $C$ 真正算的东西"。不是。$C(x)$ 按定义就是"某个被干预过的网络的输出",精确、无误差。近似发生在**下一层**——$F(C)\approx F(M)$(faithfulness),那才是有误差($0.46$)、需检验的断言。**不要把这两个 $\approx$ 混为一谈:定义($C(x):=\dots$)是精确的;faithfulness($F(C)\approx F(M)$)才是近似的。**

**4)所以"什么含义"——具体就是这个含义**

"电路 $C$ 的行为"现在的确切含义是:

> **一个从输入句子 $x$ 到输出 logits 的映射:把 GPT-2 里所有不属于 $C$ 的头换成它们在 $p_{\text{ABC}}$ 上的均值,跑前向传播,得到的那组 logits。**

完全可操作、可计算。有了它,$F(C)$、$F(C\setminus K)$ 才都算得出来,后面三个验证判据才有对象可算。

**5)诚实补充(这正是全文要操心的事)**

"$C(x)$ 是精确定义" **≠** "$C(x)$ 就是对'机制'的正确刻画"。定义是精确的(给定 knockout 方法后毫无含糊);但"这个被定义出来的对象是否真抓住了'模型负责该行为的那部分'"**不由定义保证**,恰恰是 faithfulness / completeness / minimality 要**检验**的。→ 第 1 层负责把"$C$ 的行为"变成**有定义、可计算**;验证层才回答这个定义**好不好、可不可信**。

## 1.4 怎么 knockout?—— 为什么是"均值消融 over $p_{\text{ABC}}$"

"敲掉"具体怎么操作,直接决定结论可不可信。作者的选择链:

1. **零消融**(设为 $0$):最简单,但 $0$ 是个任意值,会把后续层推到**分布外**,噪声大。**弃用**。
2. **均值消融(mean ablation)**:把节点激活换成它在某个**参考分布**上的**平均激活**。
   - 关键性质:平均会**抹掉分布里"变化"的信息**(比如具体是哪个名字),但**保留"恒定"的信息**(比如"这个位置是个名字")。
3. **参考分布选 $p_{\text{ABC}}$**(把两名字 IO/S 换成三个无关随机名字 A/B/C):
   - 为什么不用 $p_{\text{IOI}}$ 本身求均值?因为有些对任务有用的信息在 $p_{\text{IOI}}$ 里是**恒定的**(例如"有个名字被重复了"),用 $p_{\text{IOI}}$ 求均值抹不掉它,消融就"没消干净"。换到 $p_{\text{ABC}}$,"名字重复"这件事就变成了会被平均掉的信息。
   - 而且均值是**按模板、按位置分别求**的——保证"这个位置语法上是主语/动词/连词"这类语法信息在平均后仍然恒定,不被破坏。

> 用数据挖掘的话:选参考分布 = 选一个**合适的 null**,让你想抹掉的"任务信号"恰好落在被平均掉的那部分,而语法骨架作为背景被保留。

## 1.5 度量 $F$

有了 $C(x)$,就能定义质量度量:

$$F(C) \;\triangleq\; \mathbb{E}_{x\sim p_{\text{IOI}}}\big[\,\text{logit diff}(C(x))\,\big]$$

$F(M)$ 是完整模型的同一个量。后面所有验证(faithfulness 比 $|F(M)-F(C)|$、completeness 比 $|F(C\setminus K)-F(M\setminus K)|$)都建立在这个 $F$ 上。

### 补充:把公式逐个拆开(logit diff / $p_{\text{IOI}}$ / $F$)

**1)logit 是什么**

模型前向的最后一步,输出一个长度=词表大小的向量,每词一个分数,叫 **logit**;之后过 softmax 才成概率。logit = "过 softmax **之前**的原始分数",越大越倾向输出该词。

**2)logit diff = 两个候选词的 logit 相减**

对句子 "When Mary and John went to the store, John gave a drink to ___",在**最后位置**上:
$$\text{logit diff} = \text{logit}(\text{Mary}) - \text{logit}(\text{John})$$

- Mary = IO(正确),John = S(错误)。示意:若 logit(Mary)=10.5、logit(John)=7,则 logit diff=3.5。
- **正**=偏向正确;**越大**=越自信;**负**=答错。实测 GPT-2 small 均值 $3.56$(99.3% 情况下 Mary 高于 John)。

**为什么用"差"而非准确率/概率:**
1. **隔离任务信号**:IOI 本质二选一(Mary 还是 John),其他词是干扰;相减只留这两个的较量。
2. **抵消混淆**:凡是同时抬高 Mary 和 John 的通用信号(如"这里该填名字")相减时被约掉,只剩"偏向谁"。
3. **连续、带符号、线性**:准确率是 0/1 看不出细微变化;logit diff 在 softmax **之前**、对残差流**线性**——这正是 direct logit attribution(把头输出投影到 $W_U[\text{Mary}]-W_U[\text{John}]$ 方向)能**可加拆开**的前提。

**3)$x\sim p_{\text{IOI}}$ 是什么**

$x$ = 一条具体输入句子(prompt);$p_{\text{IOI}}$ = 生成这些句子的**分布/过程** = 15 个模板 × 随机单 token 名字/地点/物品 × 两种名字排列。"$x\sim p_{\text{IOI}}$" = 从这个分布**采样**一条句子。(数据挖掘语言:$p_{\text{IOI}}$ 是生成分布,$x$ 是一条 instance。)

**4)整条公式从里到外读**

$$F(C) \;\triangleq\; \mathbb{E}_{x\sim p_{\text{IOI}}}\big[\,\text{logit diff}(C(x))\,\big]$$

1. $C(x)$:补集均值消融后的网络喂进 $x$,得到 logits。
2. $\text{logit diff}(C(x))$:算 Mary−John 的差 → **这一句上的得分**。
3. $\mathbb{E}_{x\sim p_{\text{IOI}}}[\cdots]$:对很多采样句子求平均 → 一个**单一数字**,概括"电路 $C$ 平均把 IOI 做得多好"。

所以 $F(C)$ = 尺子读出的刻度:$F(M)=3.56$ 是完整模型的分,两者一比(faithfulness)就知道电路还原了多少。

**第 1 层小结**:$M$=计算图 → $C$=子图(pattern)→ knockout $M\setminus C$ 把子图变成函数 $C(x)$(赋值)→ 用 $F$ 打分。这套地基把整篇文章的"发现"和"验证"都架在了同一个可计算的量上。

# 补充:"子图能不能拎出来单独跑?" —— "删掉跑 = 零消融"

> 疑问:我把不在电路里的节点删掉,子图仍是连通的,它应该能跑。为什么说 $C(x)$ 没定义?这种做法相比均值消融差在哪?

## 1. 纠正:它确实能跑,因为残差流是"加法总线"不是"接线图"

transformer 里**没有离散的电线**。残差流是固定 $d$ 维向量,是所有上游写者的**和**:
$$z^{l-1} = x_{\text{embed}} + \sum_{\text{所有上游头}}(\text{输出}) + \sum(\text{MLP})$$

- 删掉一个不在电路里的头 $A$,残差流**维度不变**(还是 $d$ 维),只是少了 $A$ 那个加数:$z^{l-1}_{\text{新}} = z^{l-1} - a_A$。
- 下游电路里的头 $B$ 照样读这个 $d$ 维向量、照样算 $q=zW_Q$、照样输出。**前向传播一路畅通。**

所以"子图连通就能跑"是对的。

## 2. 但"能跑" ≠ "$C(x)$ 有定义"——你被迫做了个**隐藏选择**

问题不在能不能跑,在于:**删掉 $A$ 的那一刻,等于替 $A$ 在总线上填了一个值——那个值是 $0$。**

- 下游 $B$ 的输入 $z^{l-1}$ 里,$A$ 本来占一个加数位置。你"删掉"它,这个位置不会凭空消失(维度固定),它被填成了 **$0$**。
- 即:**"删掉节点然后跑" ≡ 把该节点输出设为 $0$ ≡ 零消融(zero ablation)。**

这就是论文原话(§ Background):

> "A first naïve knockout approach consists of simply deleting each node... **The net effect of this removal is to zero ablate $K$**, meaning that we set its output to 0."

所以"$C(x)$ 在数学上还没定义"的**准确含义**是:$C(x)$ 这个函数,**在你指定"被删节点填什么"之前是不唯一的**——填 $0$ 是一种选择,填均值是另一种,给出**不同的** $C(x)$。这正是论文 "we associate each circuit $C$ with a function $C(x)$ **via knockouts**" 的确切意思。

## 3. 于是"删掉跑"(=零消融) vs 均值消融,差在哪

**缺点 A:$0$ 是分布外的值,把下游推离数据流形**

- 训练中任何头的输出**从不为零向量**;下游是在"总线上一直有这个加数"的前提下学出来的。
- 突然把某加数抽成 $0$ = 给下游喂一个训练中**没见过**的残差流 → 后面头的注意力、LayerNorm 缩放都可能乱掉 → **噪声大**(论文:"zero ablation to lead to noisy results in practice")。

**缺点 B:$0$ 把"恒定基线"也一起抹了,抹得太多**

一个头的输出粗略可拆成两部分:
$$a_A \approx \underbrace{\bar{a}_A}_{\text{恒定基线}} + \underbrace{(a_A - \bar{a}_A)}_{\text{随输入变化的部分}}$$

- 你只想抹掉**随任务变化**的那部分(如"具体搬哪个名字")。
- **零消融把两部分都抹成 $0$**——连恒定基线也删了,而下游可能依赖它当隐式 bias,于是误伤了与任务无关的东西。
- **均值消融**把 $a_A$ 换成 $\bar{a}_A$(在 $p_{\text{ABC}}$ 上求的均值):**变化的部分被抹掉,恒定基线被保留**,也没把下游推到分布外(因为 $\bar{a}_A$ 是真实激活尺度的向量)。

> 一句话对比:
> - **删掉跑 / 零消融**:节点贡献设为 $0$ → "这个头**消失了**"(基线也没了,且 $0$ 分布外)。
> - **均值消融**:节点贡献设为均值 → "这个头**还在、还在正常范围,只是不再携带任务特定信息**"。
>
> 做**行为归因**要的是后者:保留"它是个搬名字的头"这个事实,只删掉"它这次搬的是哪个名字"。

**Note:零消融和均值消融是两种不同的 $C(x)$ 定义。** 论文**没有量化对比**二者——正文只有一句定性断言("zero ablation leads to noisy results in practice"),附录无对比小节。选均值(over $p_{\text{ABC}}$)靠的是原理论证 + 一句经验。→ 迁移 TFM 时可补做:三种消融各跑一遍同一套度量,看结论是否对定义敏感。

# 补充:边(edge)从计算上如何理解 —— "边 = QKV 上的可分离项"

核心一句:**边不是一根实体连线,而是"上游谁写、下游谁读、读到没读到"这件事,靠残差流的线性可加性变成一个可分离的计算项。**

## 1. 先分清两个动作:写(write)和读(read)

残差流 $z$ 是一条被所有组件**共享**的总线。每个节点对它做两件事:

- **写(write)**:注意力头把自己的输出**加**回残差流。第 $l$ 层:
$$z^{l} = z^{l-1} + \underbrace{a^l}_{\text{attn 写}} + \underbrace{m^l}_{\text{MLP 写}}$$
  一个头的输出 $= A\,(z\,W_V)\,W_O$,写进去的"内容"由 **OV 电路** $W_{OV}=W_O W_V$ 决定。**注意:写是无条件的、广播式的**——头总是把结果加进整条总线,不挑收件人。
- **读(read)**:下游头 $B$ 从当前残差流里**投影**出自己的 query / key / value:
$$q_B = z\,W_Q^B,\qquad k_B = z\,W_K^B,\qquad v_B = z\,W_V^B$$
  **读是有选择的**——$B$ 只"看得见"它的读矩阵 $W_Q/W_K/W_V$ 能挑出来的那个子空间。

所以"节点通过残差流交互"= **A 往总线上写,B 从总线上读**。边存不存在,取决于 **B 读的子空间和 A 写的子空间有没有重叠**。

## 2. 关键:线性可加让"边"变成一个**可分离的项**

残差流是**一路加出来的和**:
$$z^{l-1} = x_{\text{embed}} + \sum_{\text{上游的头 }A}(\text{A 的输出}) + \sum(\text{上游 MLP})$$

现在看 $B$ 读 value 这个动作。因为 $W_V^B$ 是线性的,把上面的和代进去:
$$v_B = z^{l-1} W_V^B = x_{\text{embed}}W_V^B \;+\; \sum_{A}\big(\underbrace{(\text{A 的输出})\,W_V^B}_{\text{A → B.value 这条边}}\big) \;+\;\cdots$$

**$B$ 的 value 输入,天然就是一堆项的和,每一个上游写者 $A$ 贡献其中一项。** 那一项 $(\text{A 的输出})W_V^B$ 就是**边 $A\to B.\text{value}$ 的计算实体**。

- 这就是为什么"边"是良定义的:不是比喻,而是残差流线性性给出的一个**具体加数**。
- 在权重层面,把 A 的写矩阵和 B 的读矩阵直接**复合**,得到这条边的"虚拟权重"(Elhage 的说法):$A\to B.\text{value}$ 对应 $W_O^A W_V^B$。这就是不跑数据、光看参数就能算的"边强度"。

## 3. 一条边其实有**三种类型**:Q / K / V 三种 composition

因为 $B$ 有三个读口(Q、K、V),从同一个 $A$ 到同一个 $B$,其实可以有**三条不同的边**:

| 边的类型 | A 写进了 B 的哪个读口 | 改变了 B 的什么 |
|---|---|---|
| **Q-composition** | $A$ 的输出 $\to B$ 的 query | B **往哪看**(注意力模式) |
| **K-composition** | $A$ 的输出 $\to B$ 的 key | B **往哪看**(注意力模式) |
| **V-composition** | $A$ 的输出 $\to B$ 的 value | B **搬运什么内容** |

对应 QK/OV 二分:

- 进 **Q 或 K** 的边 → 影响 $B$ 的 **QK 电路 $W_{QK}$** → 改变 $B$ 的**注意力去向**。
- 进 **V** 的边 → 影响 $B$ 的 **OV 电路** → 改变 $B$ **搬的东西**。

## 4. 这正好解释了论文为什么那样追电路

发现链的每一步都能翻译成"哪种边":

- "谁影响 Name Mover 的 **query**" → 找**进 NM 的 Q-composition 边** → S-Inhibition 头(它改变 NM 往哪看,把注意力从 S 推向 IO)。
- "谁影响 S-Inhibition 的 **value**" → 找**进它的 V-composition 边** → Duplicate/Induction 头(它们把"S1 位置"这个内容喂进 S-Inhibition 搬运)。

**所以 path patching 里说的"路径/边"是有方向、有类型的**:不是"$A$ 影响 $B$"这么笼统,而是"$A$ 通过 V-composition 影响 $B$"。指定路径,本质上就是指定"从哪个写口出发、进下游哪个读口"。

## 5. 一个重要的推论(为什么非得用 path patching)

既然**每个上游节点都往总线上写、每个下游节点都从总线上读**,那么原则上 $M$ 里**几乎每条边都"存在"**(每个加数都非零)——这张图是**稠密**的。

- 光靠"边存不存在"没意义,因为答案基本都是"存在"。
- 真正的问题是:**哪些边对这个行为真正起作用?** 虚拟权重 $W_O^A W_{\{Q,K,V\}}^B$ 只告诉你"参数上有没有可能"(必要条件),但不告诉你"在真实输入上是否真的在用"。
- **path patching 就是那个用因果干预去检验"这条边在真实运行时到底重不重要"的工具**——它把某条边上的贡献换成污染值,看行为掉多少。稠密图 → 靠因果效应筛出稀疏的关键边,这就是"发现电路"的实质。
