# 【临时/scratch】IOI · path patching 详细版(四趟前向)

> 基于论文附录 A(Algorithm: Path patching)的精确机制讲解。关键:是**四趟前向 A/B/C/D**,不是粗略的三趟。
> 精炼版见 [[ioi-tech-core]] 第 4 节;概念铺垫见 [[_scratch-ioi-layer2-path-patching]]。

## 一、它回答的问题(一句话)

> 头 $h$ **专门通过"直接送给 $R$"这条路**,对输出有多大因果作用?——其中"直接" = 只走残差 + MLP,**不经过其他注意力头**。

## 二、四个要素

- $x_{\text{orig}}$:干净输入(来自 $p_{\text{IOI}}$)。
- $x_{\text{new}}$:污染输入(对应的 $p_{\text{ABC}}$ 句子)。
- **sender $h$**:被测的那个头。
- **receiver $R$**:一组接收组件($h$ 的信息"发到哪")。$R$ 可以是——
  - **残差流末态**(= 直接测对 logits 的效应),或
  - 一组头的 **Q / K / V 输入**(测 $h$ 是否专门喂进某些头的 query/key/value)。

> **记号 $A$(激活缓存)**:$A_x$ = 在输入 $x$ 上跑一遍、把**所有节点的输出**存下来的缓存本;$A_x[h]$ = 取其中 $h$ 的那一项 = $h$ **吐出来、加进残差流的输出向量**(不是喂给 $h$ 的 query/key/value 输入)。所以 $A_{\text{new}}[h]$ = "$h$ 在污染句子上产出的输出"。**path patching 换的是 $h$ 发出的信息(输出),不是喂给 $h$ 的信息(输入)。**

## 三、四趟前向(核心机制,精确版)

| 趟     | 跑在                | 干什么                                                                       | 目的                                  |
| ----- | ----------------- | ------------------------------------------------------------------------- | ----------------------------------- |
| **A** | $x_{\text{new}}$  | 缓存所有激活                                                                    | 拿到 $h$ 的**污染值** $A_{\text{new}}[h]$ |
| **B** | $x_{\text{orig}}$ | 缓存所有激活                                                                    | **干净基线** $A_{\text{orig}}$          |
| **C** | $x_{\text{orig}}$ | ①$h$ 换成污染值;②**其余所有注意力头冻结在干净值**;③MLP / LN 照常重算;④读出接收点 $r\in R$ 被改成什么 → 存起来 | **隔离**出 $h$ 对 $r$ 的**直接**影响         |
| **D** | $x_{\text{orig}}$ | 把接收点 $R$ 钉在 C 存下的值;**其余全部照常重算**(其他头这时解冻);读 logits                         | 让"$r$ 被 $h$ 改变"传到输出,测 logit diff    |

> 特例:若 $R$ = logits(残差末态),D 退化——在 C 里直接读 logits 即可,不用第四趟。

## 三·补、数学表述:path patching 在算什么

记号:$a_h(x)$ = 头 $h$ 在输入 $x$ 上的**输出**;$\mathcal{L}(\pi)=\pi[\text{IO}]-\pi[\text{S}]$ = logit diff;$\mathcal{H}$ = 全部注意力头。

### (1) 操作式定义(= 四趟算法的翻译)

干净/污染输出:$a_h^{\text{new}} = a_h(x_{\text{new}})$,$a_p^{\text{orig}} = a_p(x_{\text{orig}})$。

**C 趟**——算被污染后的接收端值 $r^\ast$(对每个 $r\in R$):

$$r^\ast \;=\; r\Big(\,x_{\text{orig}} \;\Big|\; \underbrace{\mathrm{do}\big(h = a_h^{\text{new}}\big)}_{\text{只污染 }h}\,,\ \underbrace{\mathrm{do}\big(p = a_p^{\text{orig}},\ \forall p\in \mathcal{H}\setminus\{h\}\big)}_{\text{其余所有头冻结在干净值}}\,\Big)$$

(MLP / LN 不冻,照常重算。)

**D 趟**——把接收端钉住,让改动传到输出:

$$\pi^\ast \;=\; M\Big(\,x_{\text{orig}} \;\Big|\; \mathrm{do}\big(r = r^\ast,\ \forall r\in R\big)\,\Big)$$

**path patching 计算的量:**

$$\boxed{\;\Delta_{h\to R} \;=\; \mathbb{E}_{(x_{\text{orig}},\,x_{\text{new}})}\Big[\,\mathcal{L}(\pi^\ast)\;-\;\mathcal{L}\big(M(x_{\text{orig}})\big)\,\Big]\;}$$

对 $N>200$ 对 $(x_{\text{orig}}, x_{\text{new}})$ 求平均。**越负(掉得越多)→ 边 $h\to R$ 越关键。** 特例 $R=$ logits 时 $\pi^\ast$ 即 C 趟直接读出的 logits。

### (1·补)为什么要这么干预?(C 趟 + D 趟两段式的动机)

**想测什么**:边 $h\to R$ 对最终答案的效应。它有两个半程——前半程"$h$ 的消息 → 改变 $R$",后半程"$R$ 被改 → 影响输出"。诉求是:**只让前半程走 $h\to R$ 这条直接边,后半程照真实网络自然发生**。这直接决定了两段式。

对比两个"更省事"的错误做法,就懂每一步为何非如此:

- **错误做法 1:直接消融 $h$(普通 patching)**。$h$ 影响输出有很多条路($h\to R$、$h\to$别的头$\to$输出),测到的是**总效应**,分不出 $h\to R$,且被自修复污染。→ 所以 C 趟要**冻结其他头**:掐断 $h$ 走别的头的路,只留直接路,**干净算出"$R$ 被这条边改成什么" = $r^\ast$**。
- **错误做法 2:在 C 趟(冻结态)直接读 logits**。此时别的头全冻死 = 一个**残废的人造网络**,其输出不代表真实模型反应。冻结只是**算 $r^\ast$ 的临时工具**。→ 所以要 D 趟:**解冻**、回到正常网络,只把 $R$ 钉在 $r^\ast$(注入"由 $h$ 直接边造成的那点 $R$ 变化"),让真实下游自然反应再读输出。

**两段分工**:
- **C 趟**:用"冻结"当手术刀,**隔离出** "$R$ 因 $h$ 的直接边而产生的变化" → $r^\ast$。
- **D 趟**:把这点变化**注入正常网络**,测**真实下游后果**。
- 少 C 分不清是哪条边;少 D 读的是残废网络。合起来 = "边 $h\to R$ 沿直接路、经真实下游、对输出的效应"。

**类比**:测员工 $h$ 递给经理 $R$ 的报告对公司决策(logits)多重要——别直接开除他(消融=总效应、且有人顶替=自修复);而是 (C) 先算"只打乱他这一份、其他人不变,经理简报会变成什么" = $r^\ast$,(D) 再把改过的简报交给经理、公司其余照常运转,看决策变多少。

**为什么取差 + 期望**:差 = "污染这条边后答案退化多少"(边际损失,掉得多=扛关键信息);期望 = 对多对句子平均、压噪声、得普遍重要性。

### (2) 它在算什么(线性直觉)

回到 **边 = 可分离加数**:接收端 $r$ 的输入是各上游写者贡献之和,记 $h$ 送给 $r$ 的那份为 $c_{h\to r}(x)$。C 趟等价于**只把这一份从干净换成污染**:

$$\text{输入到 } r:\quad \underbrace{c_{h\to r}(x_{\text{new}})}_{\text{污染}} + \sum_{w\neq h} c_{w\to r}(x_{\text{orig}})\qquad\text{vs 干净}\quad \sum_{w} c_{w\to r}(x_{\text{orig}})$$

两者之差 $= c_{h\to r}(x_{\text{new}}) - c_{h\to r}(x_{\text{orig}})$——**恰好只有 $h\to r$ 这条边的贡献变了**。(经过的 MLP 非线性 → 要显式重算、非严格线性,即第八节的不完美之处。)

### (3) 因果语言:一个"路径特定效应"

| | 让哪些中介起作用 | 测到的 |
|---|---|---|
| **total effect**(节点消融) | **全部**中介都反应 | 混直接+间接,被自修复污染 |
| **path patching** | **其他头冻结**、只让 MLP 和 $R\to$输出 反应 | 沿路径 $h\to(\text{残差/MLP})\to R\to$输出 的效应 |
| **direct effect**(Hydra) | **全部**中介冻结 | 纯直接 |

> $\Delta_{h\to R}$ 估计的是"$h$ 沿'不经其他头'的直接路影响 $R$、再由 $R$ 传到输出"的因果效应,用 logit diff 读出——是 total 与 direct 之间的**路径特定(edge-specific)效应**。

## 四、为什么第 C 趟的"冻结其他头" = 只走直接路径

整个技术的机关:

- $h$ 想影响 $r$,有两类路:
  1. **直接**:$h \to$(残差 / MLP)$\to r$——不碰别的头。
  2. **间接**:$h \to p \to r$,中间经过另一个头 $p$。
- 第 C 趟把**除 $h$ 外所有头冻死在干净值** → 任何 $h\to p\to r$ 都被掐断($p$ 不管上游怎么变都吐干净值)。
- **只剩直接路径能把 $h$ 的污染传到 $r$。** MLP 不冻、照常重算,所以"经 MLP 的直接路"保留。
- 精确实现了"只经残差 + MLP、不经其他注意力头"。

> **冻结到底剥离了什么(易错点)**:其他头对 $r$ 的贡献**没有被删**,只是被**钉死在干净值**。真正被剥离的是"**$h$ 经由其他头、间接到达 $r$**"的那些路 → 剥离的是 **$h$ 对 $r$ 的\_间接\_影响**,不是"其他头对 $r$ 的影响"。
>
> 换个角度:其他头被摁成常量 → 它们对 $r$ 的贡献在"变化量"里**抵消** → $r^\ast$ 相对干净 $r$ 的变化**只来自 $h\to R$ 这条直接边**。

回扣 **边 = 可分离加数**:C 趟就是把 $r$ 输入里"来自 $h$ 的那一项"从干净换成污染,其他项(来自别的头)因冻结而不动。

## 五、具体例子 1:找 Name Movers(R = logits)

目标:谁**直接**往 logits 写答案?

1. A:在 "When A and B... C gave a drink to" 上跑,存每个头的污染输出。
2. B:在 "When Mary and John... John gave a drink to" 上跑,存干净激活,记下干净 logit diff(Mary−John)。
3. C:对某候选头 $h$,换成污染值、冻结其他所有头、重算 → 读末态 logits → 算新 logit diff。
4. 每个头都做一遍,看谁让 logit diff **掉最多**。
   - $9.6, 9.9, 10.0$ 让它大掉 → **Name Mover**(直接写 Mary)。
   - $10.7, 11.10$ 让它反而**升**(掉成负)→ **Negative Name Mover**(往反方向写)。

**为什么抗自修复**:C 趟把别的头全冻死,备份头**没机会激活**。所以即使"敲掉 name mover 时 backup 补偿"让**总效应**被掩盖,这里测的**直接效应**照样把真正的 name mover 暴露出来。

## 六、具体例子 2:找 S-Inhibition(R = Name Mover 的 query)

体现"**path**"的威力——靶不再是 logits,而是**上一步找到的头的某个子输入**。

1. 已知 Name Mover 靠 query 决定往哪看。设 $R$ = {Name Mover 的 query 向量}。
2. 对每个候选 $h$ 跑四趟:C 趟隔离"$h$ 直接写进 NM query 的那份",D 趟让 NM 拿着被改的 query 重算、传到 logits。
3. 看谁让 logit diff 掉得多 → $7.3, 7.9, 8.6, 8.10$ → **S-Inhibition 头**。
   - 含义:它们**不直接写答案**,而是通过**改 NM 的注意力去向**间接起作用——普通节点消融分不清,path patching 能精确定位。

**这也是发现链往上爬的一步**:靶从 logits → NM 的 query → S-Inhibition 的 value → …,每次把靶换成上一层组件的 Q/K/V,一层层剥出整张电路。

## 七、数字怎么读 + 平均

- 测的是 **D 趟(或 R=logits 时 C 趟)的 logit diff 相对干净基线掉了多少**;掉得越多 → 路 $h\to R$ 越关键。
- 对 **$N>200$ 对 $(x_{\text{orig}}, x_{\text{new}})$ 取平均**,压掉单句噪声。

## 八、诚实的边界(论文自己承认)

path patching 只是"**试图**测直接效应",不完美:

1. 当 $R$ 含多个头且分处不同层时,靠后的接收头会读到靠前接收头**被改过**的输出 → 测到"直接效应 + 接收头之间的内部间接作用"混在一起。
2. **MLP 从不冻结**,经 MLP 的间接效应可能混进来。
3. 作者明说这"不是唯一/标准的选择"。
